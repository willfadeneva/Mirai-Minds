# Grade-wise English Content Added

This file documents the Grade 1–12 curriculum now included in `data/english-curriculum.ts`.

## Grade 1 — Pre-A1 First Sounds (First Word Explorer)

**Theme:** Zero-start English: sounds, classroom words, colors, numbers, feelings

**Outcome:** Can listen, point, repeat, recognize A–Z sounds, read CVC words, and answer with one word or a short phrase.

**Vocabulary:** apple / りんご, book / 本, cat / 猫, dog / 犬, cat / 猫, dog / 犬, red / 赤, blue / 青

**Grammar frames:** I am __.; This is a __.; This is a __.; I like __.

**Story:** Grade 1: Mina and the ABC Star

**Reading items:** Picture Reader 1.1, Hadano Life 1.2, Dialogue Quest 1.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Project:** Make a picture ABC mini-book with 12 English words and Japanese meanings.

## Grade 2 — Pre-A1 Starter (Sentence Starter)

**Theme:** Words, phonics blends, family, food, toys, weather, simple questions

**Outcome:** Can read simple sentences, understand classroom instructions, ask and answer easy questions, and write short labels.

**Vocabulary:** mother / 母, father / 父, rice / ごはん, milk / 牛乳, rice / ごはん, milk / 牛乳, sunny / 晴れ, rainy / 雨

**Grammar frames:** What is it? It is __.; I have a __.; I have a __.; Do you like __? Yes, I do.

**Story:** Grade 2: Kaito's Rainy Day Words

**Reading items:** Picture Reader 2.1, Hadano Life 2.2, Dialogue Quest 2.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Project:** Create a weather wheel and say one English weather sentence each day.

## Grade 3 — A1 Explorer (Routine Explorer)

**Theme:** Daily routines, school life, places, time, simple story reading

**Outcome:** Can read short paragraphs, describe routines, use simple present, and answer who/what/where questions.

**Vocabulary:** Monday / 月曜日, library / 図書館, park / 公園, math / 算数, park / 公園, math / 算数, music / 音楽, breakfast / 朝ごはん

**Grammar frames:** I wake up at __.; I go to __.; I go to __.; There is/are __.

**Story:** Grade 3: The Map to Hadano Library

**Reading items:** Picture Reader 3.1, Hadano Life 3.2, Dialogue Quest 3.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Project:** Draw a town map and present five places using There is/There are.

## Grade 4 — A1 Builder (Story Builder)

**Theme:** Hobbies, descriptions, past moments, longer dialogues, reading confidence

**Outcome:** Can describe people and places, compare simple ideas, read dialogues, and write 5–7 connected sentences.

**Vocabulary:** mountain / 山, river / 川, drawing / 絵を描くこと, visited / 訪れた, drawing / 絵を描くこと, visited / 訪れた, because / なぜなら, strong / 強い

**Grammar frames:** I was __ yesterday.; I played/watched/visited __.; I played/watched/visited __.; My favorite __ is __ because __.

**Story:** Grade 4: The Fox by Mizunashi River

**Reading items:** Picture Reader 4.1, Hadano Life 4.2, Dialogue Quest 4.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Project:** Write and illustrate a 7-sentence nature story set in Hadano.

## Grade 5 — A2 Story Reader (Adventure Reader)

**Theme:** Adventure stories, opinions, comparisons, community and culture

**Outcome:** Can read graded stories, express opinions with reasons, compare things, and write organized short paragraphs.

**Vocabulary:** community / 地域, helper / 助ける人, journey / 旅, cloudy / 曇り, journey / 旅, cloudy / 曇り, faster / より速い, interesting / 面白い

**Grammar frames:** I think __ because __.; __ is bigger/faster/more interesting than __.; __ is bigger/faster/more interesting than __.; First/Next/Then/Finally, __.

**Story:** Grade 5: The Cloud Train to Mount Kobo

**Reading items:** Picture Reader 5.1, Hadano Life 5.2, Dialogue Quest 5.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Project:** Create a community helper comic with dialogue and a short opinion paragraph.

**Vocabulary:** habit / 習慣, healthy / 健康的な, usually / たいてい, sometimes / 時々, usually / たいてい, sometimes / 時々, culture / 文化, future / 未来

**Grammar frames:** I agree/disagree because __.; I usually/sometimes/never __.; I usually/sometimes/never __.; I am going to __.

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

## Grade 7 — A2+ Paragraph Writer (Paragraph Engineer)

**Theme:** Paragraphs, narratives, interviews, school projects, richer vocabulary

**Outcome:** Can write clear paragraphs, conduct simple interviews, summarize stories, and explain causes and results.

**Vocabulary:** environment / 環境, technology / 技術, interview / インタビュー, result / 結果, interview / インタビュー, result / 結果, during / 〜の間, protect / 守る

**Grammar frames:** While I was __, __ happened.; This happened because __.; This happened because __.; As a result, __.

**Story:** Grade 7: The Recycling Robot

**Reading items:** Picture Reader 7.1, Hadano Life 7.2, Dialogue Quest 7.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Theme:** Presentations, explanations, narratives, media literacy, local-global links

**Outcome:** Can discuss familiar issues, give short presentations, identify main ideas, and write summaries with details.

**Vocabulary:** evidence / 証拠, media / メディア, local / 地域の, global / 世界的な, local / 地域の, global / 世界的な, summary / 要約, example / 例

**Grammar frames:** I have learned that __.; The main idea is __.; The main idea is __.; One example is __.

**Reading items:** Picture Reader 8.1, Hadano Life 8.2, Dialogue Quest 8.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Reading items:** Picture Reader 9.1, Hadano Life 9.2, Dialogue Quest 9.3

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission

**Grammar frames:** It is said that __.; One advantage is __, while one disadvantage is __.; One advantage is __, while one disadvantage is __.; This implies that __.

**Games:** Flashcard Sprint, Sentence Builder, Story Detective, Hadano Mission
